# MarsPath development

Prioritize a deployed working atlas, all 13 scientific destinations, and validated regional routing before optional features. Preserve scientific originals. Never infer measurements from PNG colors, fabricate coordinates, sources, test results, or safety claims. Keep every dataset, image, and substantial scientific claim source-linked. Use planetocentric Mars coordinates and explicit Mars radii, never implicit Earth calculations. Respect nodata and coverage. Maintain static-export compatibility and calculate routes in a worker. Run meaningful tests, typecheck, lint and build. Commit and push coherent milestones; update the development log and status honestly. Never commit credentials, raw large rasters, node_modules, or build output. Keep the repository private until publication is authorized or verified submission requirements require it.
