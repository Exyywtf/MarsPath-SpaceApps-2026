Hello,

We are developing MarsPath, a noncommercial educational Mars atlas for the NASA Space Apps Challenge: https://marspath-spaceapps-2026.vercel.app/

We plan to visualize numerical MCD 6.2 web-interface outputs for Ls 21.3 degrees, local time 00:00 at all longitudes, 10 m above the local surface, and the climatology / average-solar scenario. The interface identifies these as modelled climatology, shows units and export sampling, and links the MCD credits, documentation and usage conditions. These fields are not presented as live weather or used as astronaut safety probabilities.

The project software is MIT licensed; MCD-derived outputs retain the MCD conditions separately. No commercial use is intended. This notice is to keep you informed of the planned usage and development, as requested by the MCD access conditions.

Thank you for making the database available.
