# Scientific method

Use original institutional and publication sources for scientific statements, imagery, coordinates and numerical terrain. The supplied research was a starting point; concise displayed statements are linked to their sources rather than copying unsupported detailed claims.

Use IAU/USGS planetocentric, east-positive feature centres as representative region markers. Gusev's marker is the broad crater centre, not a measured Columbia Hills target. Eridania's marker represents a published northern-basin rim example, not the unrelated classical albedo feature called Eridania. Terra Sirenum uses NASA's approximate 221°E, 38.8°S chloride-deposit location. Coordinates and their caveats are attached to each record.

Preserve numerical source rasters and nodata. Inspect CRS, transform, units, bounds and resolution before producing derivatives. The CTX float32 nodata decimal is near the representational limit; explicitly mask extreme sentinel and nonfinite values before differences. No nodata gaps are filled for routing.

Do not interpret screenshot pixel dimensions as scientific resolution, image colours as numerical measurements, coarse climate fields as site observations, or fine imagery as fine terrain. Report source access failures and avoid unsupported claims. Public descriptions remain concise; the full supplied research has not been independently validated in its entirety.
